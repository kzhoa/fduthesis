# English thesis example

Open `thesis.pdf` for a preview. To build your own copy, open `main.tex`
in Overleaf and select XeLaTeX, or run `latexmk -xelatex -jobname=thesis main.tex` from
this directory. The example uses Times New Roman and Biber.

With `lang=en`, the contents, chapters, captions and references use English.
On the cover, set `title` to the Chinese title and `title-en` to its English
translation. The example includes a Chinese committee page, a Chinese
abstract followed by an English abstract, and the Chinese declarations on
the last page. Edit both abstracts and their respective keyword lists in
`main.tex`.
